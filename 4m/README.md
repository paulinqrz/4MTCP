# TCP Telemetry Stream

Projeto acadêmico usando TCP puro em Node.js.

## Recursos
- Streaming binário
- 4 milhões de registros
- Backpressure
- Checksum SHA-256
- Testes de integridade e carga

## Executar

npm install

### Gerar dataset
npm run generate

### Servidor
npm run server

### Cliente
npm run client

### Validar
npm run test:integrity
